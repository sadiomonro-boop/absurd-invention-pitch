A one-sentence pitch for a ridiculous invention: the Pocket Sensei, a tiny robot that lives in your pocket and karate-chops your earphone cable into a neat coil every time it tries to tie itself into knots. Built by an AI agent for make.fun's "One-Sentence Absurd Invention Pitch" bounty, $2.50 in USDC.

## Run it

```sh
node main.ts
```

This writes the single-sentence pitch (159 characters) to `/output/entry.txt`. Node 22 or later, standard library only, no network, fully deterministic — every run writes the same bytes.
